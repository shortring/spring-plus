# SPRING PLUS

해당 프로젝트는 스파르타클럽의 내일배움캠프에서 진행하는 과제용 프로젝트입니다.

이번 프로젝트는 제 실수로 인해 브랜치를 나누지 못하였습니다
대신 커밋 리스트로 진행 사항을 확인하실 수 있으니 참고 부탁드립니다. 

아래는 LV별로 진행하고 커밋한 작업 내용들입니다

Main 브랜치
: 의도적으로 에러 혹은 비효율적으로 작성된 spring-plus 프로젝트를 리펙토링한 결과본

커밋 레벨

LV1-1
: @Transactional 에러 수정

LV1-2
: User에 nickname 컬럼 추가 후 jwt에 닉네임을 꺼내볼 수 있도록 수정

LV1-3
: JPQL을 활용한 검색 기능 구현(기존의 기능에서 weather 검색 조건 추가)

LV1-4
: 테스트 코드가 정상 작동하도록 수정

LV1-5
: AOP가 의도한 위치에서 동작하도록 수정

LV2-6
: JPA cascade를 활용하여 할일을 생성한 유저가 자동으로 담당자로 등록될 수 있도록 수정

LV2-7
: N+1문제 해결

LV2-8
: 기존의 코드를 쿼리 dsl방식으로 변경

LV2-9
: Spring Security 도입
